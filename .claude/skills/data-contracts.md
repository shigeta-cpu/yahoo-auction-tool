# データ入出力・仕様契約（data-contracts）

> プリセット定義・帯レイアウト仕様・入出力の正式な契約を管理する。
> プリセット項目や帯サイズが変わったら必ずここを更新すること。

## 1. 入力契約

### 元画像
- 形式: JPEG / PNG（ブラウザで読み込めるラスター画像）
- アスペクト比: 任意（正方形・縦長・横長すべて可。16:9 を主に想定）
- サイズ違いの扱い: 読み込み後、写真領域内で**ドラッグ移動＋拡大縮小（view 変換）**して構図調整。初期は全体表示（contain）。はみ出しは出力でクリップ。
- 読み込み方法: ファイル選択 or ドラッグ&ドロップ
- 制約: ブラウザ内で処理（外部送信しない）

## 2. 出力契約

- 形式: JPG（品質0.95・★暫定。ヤフオクが gif/jpg のみ対応のため PNG から変更）。`toBlob('image/jpeg', 0.95)`
- アスペクト比: 厳密に 1:1（正方形）
- 解像度: 元画像の実ピクセルを最大限維持（JPGでも解像度は非圧縮のまま）
- 出力先: 端末にダウンロード
- ファイル名規則: ★暫定 `yahoo-auction-YYYYMMDDhhmmss.jpg`

## 3. 帯レイアウト契約

### 全体構成
```
上帯（キャッチコピー帯） / 写真（16:9） / 下帯（バッジ帯）
→ 合計が 1:1 になる
```

### 寸法（比率で管理・解像度非依存）
- 出力 1 辺: `S`（元画像の実幅基準）
- 写真部: 幅 `S`、高さ `S * 9/16` (=0.5625 S)
- 上下帯合計: `S * 7/16` (=0.4375 S)
- 上帯 : 下帯 の高さ配分: 上 `0.114 S`（ブランド帯・左寄せ短縮版の帯画像4000×456のアスペクト比に一致＝歪みゼロ） / 下 `0.21 S`（正方形バッジ帯）
- 写真部 = 残り `0.676 S`（cover。端数を吸収し合計を厳密に 1:1）
- 実装: `js/renderer.js` `LAYOUT` 定数 / `computeLayout` / `getDefaultView` / `drawPhoto`
- 任意サイズ入力: 写真領域内で view 変換（scale=base×ズーム, cx/cy 移動）。初期=contain中央、ドラッグ移動＋スライダー拡縮、領域外はクリップ（出力=正方形のまま）

## 4. プリセット定義

### 上帯（ロゴ帯）
| キー | ラベル | ロゴ | テキスト | 背景 | 備考 |
|------|-------|------|---------|------|------|
| brand | ロゴ＋ジムニーリユースパーツ | （帯画像に内包） | JIMNY REUSE PARTS / ジムニーリユースパーツ | #ffd200 | リファレンス完全一致の帯画像を全幅に貼付 |
| none | 上帯なし | — | — | 白 | 帯なし（1:1は維持） |

- **ブランド上帯は「リファレンス完全一致の帯画像」（4000×555px）をそのまま貼る方式**。C.L.LINKロゴ＋区切り線＋「JIMNY REUSE PARTS」＋「ジムニー リユースパーツ」＋横罫が1枚の画像に内包される。
  - 理由: フォント生成では参照デザインの書体と完全一致できないため。画像なら**Mac/Windows/オフライン(file://)で完全に同一表示・ピクセル一致**。
  - 実体: `js/topband-data.js`（`window.TOPBAND_DATA_URL`・base64データURI埋め込み）。素材 = 4000×456の**左寄せ・上下同一パディング・短縮版**（左余白112px、上下余白同一、帯高を元4000×555から短縮）。素材元 = `~/Downloads/CLLINK_upper_band_4000px_exact.svg` の埋め込みPNGをPILで再レイアウト。
  - 描画: `renderer.js` `drawTopBand` が `topPreset.key==='brand'` かつ帯画像ロード済みなら `ctx.drawImage(bandImg,0,band.y,S,band.h)` で全幅貼付。未ロード時のみ従来のロゴ+テキスト描画にフォールバック。
  - 帯高は画像アスペクト比(456/4000=0.114)に一致させ横方向の歪みゼロ。
- （フォールバック用）従来ロゴ: 黒ロゴ→輝度アルファ変換で透過し余白トリミングして描画（`getProcessedLogo`）。`js/logo-data.js`（`window.LOGO_DATA_URL`）に base64 埋め込み。`getImageData` は try/catch 保護。

### 下帯（バッジ帯）— 項目ごと選択・テキストのみ（マークなし）
| キー | ラベル | タイプ | 選択肢 | バッジ表記 |
|------|-------|-------|--------|-----------|

| tire | タイヤの種類 | 択一 | サマー / スタッドレス | 小「タイヤ」＋大「値」 |
| usage | 使用年数 | 択一 | 1ヶ月未満 / 半年未満 / 1年未満 / 1～2年 / 3～5年 / 5年以上 / 不明 | 小「使用年数」＋大「値」 |
| mileage | 走行距離 | 択一 | テスト走行程度 / ～1,000km / ～5,000km / ～20,000km / 20,000km～ / 不明 | 小「走行距離」＋大「値」 |
| year | 製造年数 | 複数(最大4) | 2027年 / 2026年 / 2025年 / 2024年 / 2023年 / 2022年 | 小「製造年」＋年を集約(1バッジ) |

- バッジ = 角丸正方形・固定サイズ（5個基準）・**カテゴリ別ビビッドカラー＋光沢グラデ**+白文字・マークなし。
- カラー（`presets.js` `BADGE_COLORS`／★暫定・参考画像と非類似の別配色）:
  | key | 色 | hex |

  | rank | クリムゾン | #c0392b |
  | tire | ブルー | #2563c9 |
  | usage | スレートグレー | #5d6d7e |

  | guarantee | グリーン | #1f9a4d |
  | bihin | マゼンタ | #c2317f |

- 質感（`renderer.js` `drawBadgeSquare`）: 縦グラデ（上明30%→中ベース→下暗38%）＋上半分グロス＋内側白縁＋白文字影。フラット塗りの参考画像と差別化。
- 最大5個。5未満はセンター寄せ（左右均等の空白）、5超は自動縮小。表示順: 状態→ランク→タイヤ→適合型式→保証付→美品→バリ溝。
- 描画仕様は lines=[{t,r,w}]（t:文字/r:辺比サイズ/w:太さ）＋ color（バッジ色）で main.js が生成、renderer.js が描画。

## 5. バリデーション

- 元画像が未選択のまま生成しようとした → エラー表示
- 元画像が 16:9 から大きくずれている → 警告 [挙動要決定]
- バッジ未選択でも生成可（帯は空 or 非表示）[要決定]
