# データ入出力・仕様契約（data-contracts）

> プリセット定義・帯レイアウト仕様・入出力の正式な契約を管理する。
> プリセット項目や帯サイズが変わったら必ずここを更新すること。

## 1. 入力契約

### 元画像
- 形式: JPEG / PNG（ブラウザで読み込めるラスター画像）
- 想定アスペクト比: 16:9
- 16:9 でない場合の扱い: [未確定 → SPEC「未解決課題」参照]
- 読み込み方法: ファイル選択 or ドラッグ&ドロップ
- 制約: ブラウザ内で処理（外部送信しない）

## 2. 出力契約

- 形式: JPG（品質0.95・★暫定。ヤフオクが gif/jpg のみ対応のため PNG から変更）。`toBlob('image/jpeg', 0.95)`
- アスペクト比: 厳密に 1:1（正方形）
- 解像度: 元画像の実ピクセルを最大限維持（JPGでも解像度は非圧縮のまま）
- 出力先: 端末にダウンロード
- ファイル名規則: ★暫定 `yahoo-auction-YYYYMMDDhhmmss.jpg`

## 3. 帯レイアウト契約

### 全体構成
```
上帯（キャッチコピー帯） / 写真（16:9） / 下帯（バッジ帯）
→ 合計が 1:1 になる
```

### 寸法（比率で管理・解像度非依存）
- 出力 1 辺: `S`（元画像の実幅基準）
- 写真部: 幅 `S`、高さ `S * 9/16` (=0.5625 S)
- 上下帯合計: `S * 7/16` (=0.4375 S)
- 上帯 : 下帯 の高さ配分: ★暫定 上 `0.10 S`（ロゴ帯・細く） / 下 `0.21 S`（正方形バッジ帯）
- 写真部 = 残り `0.69 S`（cover。端数を吸収し合計を厳密に 1:1）
- 実装: `js/renderer.js` `LAYOUT` 定数
- 16:9 外の入力: ★暫定 中央 cover 切り抜き（歪めない）

## 4. プリセット定義

### 上帯（ロゴ帯）
| キー | ラベル | ロゴ | テキスト | 背景 | 備考 |
|------|-------|------|---------|------|------|
| brand | ロゴ＋ジムニーリユースパーツ | C.L.LINK(assets/logo.png) | ジムニーリユースパーツ | #ffd200 | 左ロゴ+右テキスト |
| none | 上帯なし | — | — | 白 | 帯なし（1:1は維持） |

- ロゴは黒ロゴ→輝度アルファ変換で透過し余白トリミングして描画（`getProcessedLogo`）。
- ロゴ画像は base64 データURIで `js/logo-data.js`（`window.LOGO_DATA_URL`）に埋め込み、`main.js` が優先読込（file:// で開いた際の canvas taint 回避のため。error-catalog [2026-07-24] 参照）。`getImageData` は try/catch 保護。

### 下帯（バッジ帯）— 項目ごと選択・テキストのみ（マークなし）
| キー | ラベル | タイプ | 選択肢 | バッジ表記 |
|------|-------|-------|--------|-----------|
| condition | 状態 | 択一 | 中古 / 未使用 / アウトレット / 新品 | 小「状態」＋大「値」 |
| rank | ランク | 択一 | SS / S / A / B / C / D | 小「ランク」＋特大「値」 |
| tire | タイヤの種類 | 択一 | サマー / スタッドレス | 小「タイヤ」＋大「値」 |
| usage | 使用年数 | 択一 | 1ヶ月未満 / 半年未満 / 1年未満 / 1～2年 / 3～5年 / 5年以上 / 不明 | 小「使用年数」＋大「値」 |
| mileage | 走行距離 | 択一 | テスト走行程度 / ～1,000km / ～5,000km / ～20,000km / 20,000km～ / 不明 | 小「走行距離」＋大「値」 |
| year | 製造年数 | 複数(最大4) | 2027年 / 2026年 / 2025年 / 2024年 / 2023年 / 2022年 | 小「製造年」＋年を集約(1バッジ) |
| model | 適合型式 | 複数(最大4) | JA11/JB31/JA22/JB32/JB23/JB33/JB43/JB64/JB74/JC74/汎用 | 小「適合型式」＋型式を集約(1バッジ) |
| guarantee | 保証付 | 強制ON | — | 小「全商品」＋大「保証付」 |
| bihin | 美品 | トグル | — | 大「美品」 |
| barimizo | バリ溝 | トグル | — | 大「バリ溝」 |

- バッジ = 角丸正方形・固定サイズ（5個基準）・**カテゴリ別ビビッドカラー＋光沢グラデ**+白文字・マークなし。
- カラー（`presets.js` `BADGE_COLORS`／★暫定・参考画像と非類似の別配色）:
  | key | 色 | hex |
  |-----|----|-----|
  | condition | ティール | #0f9d8f |
  | rank | クリムゾン | #c0392b |
  | tire | ブルー | #2563c9 |
  | usage | スレートグレー | #5d6d7e |
  | mileage | シアン | #0e8ba8 |
  | year | アメジスト | #8e44ad |
  | model | インディゴ | #5b4bc4 |
  | guarantee | グリーン | #1f9a4d |
  | bihin | マゼンタ | #c2317f |
  | barimizo | アンバー | #e08a1e |
- 質感（`renderer.js` `drawBadgeSquare`）: 縦グラデ（上明30%→中ベース→下暗38%）＋上半分グロス＋内側白縁＋白文字影。フラット塗りの参考画像と差別化。
- 最大5個。5未満はセンター寄せ（左右均等の空白）、5超は自動縮小。表示順: 状態→ランク→タイヤ→適合型式→保証付→美品→バリ溝。
- 描画仕様は lines=[{t,r,w}]（t:文字/r:辺比サイズ/w:太さ）＋ color（バッジ色）で main.js が生成、renderer.js が描画。

## 5. バリデーション

- 元画像が未選択のまま生成しようとした → エラー表示
- 元画像が 16:9 から大きくずれている → 警告 [挙動要決定]
- バッジ未選択でも生成可（帯は空 or 非表示）[要決定]
